---------- patahero_api (Private) ----------
URL      : https://github.com/hafidzmulia-its/patahero_api
Live     : https://your-domain.com/api (cPanel / HostData shared hosting)
Language : PHP (Laravel)
Description: PataHero — RESTful API backend for a mobile first aid app (bone fracture treatment guides)

Tech Stack:
  Language : PHP 8.2+
  Framework: Laravel 12.0, Eloquent ORM
  Auth     : Laravel Sanctum 4.0 (token-based Bearer auth)
  Database : MySQL
  Tools    : Vite, PHPUnit 11.5, Laravel Pint, Laravel Sail (Docker dev)
  Deploy   : cPanel / HostData shared hosting

Database Models:
  - User, Fracture, FirstAidStep, AlertNotification

API Endpoints:
  Public:
    GET  /api/fracture_names            — list all fracture types
    GET  /api/first_aid_fracture_data   — fractures with step-by-step instructions + images
    POST /api/first_aid_fracture        — add custom fracture entry
    DELETE /api/first_aid_fracture      — remove fracture entry
  Auth (/api/v1):
    POST /api/v1/register | login | logout
    GET  /api/v1/me
  User (protected):
    GET/PATCH/DELETE /api/v1/user
    POST /api/v1/user/photo             — profile photo upload

Key Features:
  - Step-by-step first aid instructions per fracture type (arm, leg, spine, etc.)
  - Instructional image serving for each step (storage/app/public/)
  - Token-based authentication (Sanctum) with register/login/logout/profile
  - Profile photo upload support
  - Alert/notification system for accident events
  - Database-seeded fracture data (seeders)
