\textbf{Perihal: Lamaran Posisi Junior Web Developer}

\vspace{12pt}

Yth. Tim Rekrutmen PT Sosial Bisnis Indonesia (SOBI),

Saya menulis surat ini untuk mengajukan lamaran pada posisi Junior Web Developer di PT Sosial Bisnis Indonesia (SOBI). Saya adalah web developer dengan pengalaman hands-on membangun dan mendeploy aplikasi full-stack, khususnya menggunakan Laravel, PHP, MySQL, JavaScript, dan implementasi frontend yang responsif. Bagi saya, posisi ini menarik karena SOBI tidak hanya membangun sistem, tetapi juga menghubungkan teknologi dengan dampak nyata di lapangan.

Dalam beberapa proyek terakhir, saya terlibat langsung di sisi backend maupun frontend. Pekerjaan berbasis Laravel yang saya kerjakan antara lain \textit{sina}, platform storybook dengan role-based access dan admin CMS; \textit{SIPerpustakaan}, sistem manajemen perpustakaan dengan alur peminjaman dan analitik; serta \textit{patahero\_api}, backend REST API dengan authenticated endpoints dan structured resource handling. Dari proyek-proyek tersebut, saya mendapatkan pengalaman praktis dalam desain database relasional, workflow backend berbasis Eloquent, authentication dan authorization, integrasi API, debugging, serta maintenance aplikasi yang sudah berjalan.

Walaupun pengalaman produksi saya paling kuat ada di Laravel, saya juga memiliki exposure langsung ke Vue.js melalui proyek \textit{vue-tasty-recipes} dan pengalaman yang cukup baik dalam pengembangan frontend berbasis komponen. Karena fondasi saya di aplikasi PHP MVC sudah cukup kuat, saya yakin dapat beradaptasi dengan cepat untuk codebase berbasis CodeIgniter juga. Dari sisi deployment, saya juga terbiasa menangani rilis live, konfigurasi produksi, dan setup domain pada beberapa proyek web. Saya cukup nyaman bekerja secara mandiri dalam setup remote, sehingga model kerja kontrak dan remote di SOBI juga sesuai dengan cara kerja saya.

Saya merasa dapat berkontribusi di SOBI melalui pengembangan dan maintenance sistem web yang rapi, cukup aman, dan nyaman digunakan, sekaligus mendukung fitur-fitur berbasis API dan kebutuhan operasional yang nyata. Saya juga melihat posisi ini sebagai kesempatan yang baik untuk terus berkembang secara teknis sambil berkontribusi pada tim yang bekerja di persimpangan teknologi, komunitas, dan dampak jangka panjang.

Terima kasih atas waktu dan pertimbangannya. CV saya telah saya lampirkan, dan saya akan dengan senang hati berdiskusi lebih lanjut apabila profil saya dinilai sesuai dengan kebutuhan pengembangan web di SOBI.

Hormat saya,
